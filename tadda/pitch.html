Phase 2 — Planned Features

What's Coming Next

Phase 2 expands the platform with DIY tools, stronger access control, and operational efficiency.

Staging Ready

🎨 Mockup Builder

DIY canvas where customers upload their design PNG and position it on real product blank photos (front, back, left, right). Save mockups to library and attach to orders directly. No design software needed.

Staging Ready

🖼 Design Library

Customers save designs (with or without product canvas) to a personal library. Pick saved designs when placing future orders — no re-uploading same file every time.

Planned

👥 Role System

Super Admin (platform control), Admin (business access — up to 2 seats), Customer. Roles stored in Firestore — no hardcoded emails.

Planned

🚦 Service Levels

4-level service switch: Active → Warning → Restricted → Limited → Suspended. Super Admin controls service health without touching code.

Planned

📤 Data Export

Admin can export all orders and registrations as JSON/CSV backup. Essential for compliance and offline reporting.

Planned

📄 Invoice & Credit Notes

Auto-generated PDF invoice on order confirmation (jsPDF). Credit note PDF for cancellations and returns.

Planned

💰 Wallet System

Admin tops up customer wallet. 5% bonus on every top-up. Customers use wallet balance (partial or full) at checkout alongside Razorpay.

Planned

🏭 Vendor Portal

Vendor login with assigned orders only. Vendor updates production status. Admin assigns orders to vendors. Parallel to customer portal.

Planned

👨‍💼 Employee Management

Admin adds team members (name, phone, email). Each order can have a Primary and Secondary assignee from the team. Clear internal ownership — know who is handling what at any point, without chasing on WhatsApp.

Planned

➕ New Product Category Management

Admin can add new product categories, colours, sizes, and pricing directly from the admin panel — no code changes needed. Products appear instantly on the order form and marketing site.

Planned

🎫 Ticketing System

Customers raise queries or concerns from their dashboard. Admin views, responds to, and closes tickets. Status tracking: Open → In Progress → Resolved. Full conversation thread per ticket.

Mockup Builder is already built and tested on staging. Deployment to production can happen as soon as Phase 2 is signed off — no additional build time needed for this feature.
